# Navin Finance Intelligence

Internal hospital finance-control application for Navin Group of Hospitals. This replaces the retired patient MIS in this repository. The application is in [`finance/`](finance/README.md).

Run `cd finance && bash scripts/install.sh && bash scripts/start.sh`.

See the [delivery checklist](finance/docs/DELIVERY_CHECKLIST.md) for implemented workflows, data prerequisites and current limits. No real hospital financial reports were supplied. Demonstration figures are synthetic and stored separately from real records.
